# Historical offline placement draft

hardcoded assumptions and is not the installed fabric coordinator or a validated
placement optimizer. It is not used by the completed DeepSeek or Kimi model
demonstrations. Its output is not runtime, capacity, quality or performance proof.

Use [the fabric overview](../../docs/FABRIC.md) for current scope and the
`strata_control/fabric_*` tools for the existing explicit plan/installation path.
